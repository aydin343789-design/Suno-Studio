# Suno Studio

اپ اندروید (Kotlin) برای دانلود و تبدیل:

| بخش | کار |
|---|---|
| Suno | دانلود آهنگ از لینک عمومی (MP3) |
| یوتیوب | ویدیو (1080/720) یا فقط صدا MP3 |
| اینستاگرام | ریلز و ویدیوهای عمومی |
| فیسبوک | ویدیوهای عمومی |
| مبدل MP3 | WAV / هر صدا یا ویدیو ← MP3 (۱۲۸/۱۹۲/۳۲۰) |

- موتور یوتیوب/اینستاگرام/فیسبوک: yt-dlp + FFmpeg (کتابخانهٔ youtubedl-android) که خودکار به‌روزرسانی می‌شود.
- فایل‌ها در `Music/Suno Studio` و `Movies/Suno Studio` ذخیره می‌شوند.
- لینک را می‌توان از خود اپ‌ها با Share مستقیم به برنامه فرستاد.
- ساخت APK: Actions ← «Build Suno Studio Android APK» ← Run workflow؛ خروجی در Artifacts.
