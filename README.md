# Suno Studio — Android Native

نسخهٔ بومی اندروید Suno Studio در مسیر `android-native/` قرار دارد. این نسخه به Node.js، Express، FFmpeg سرور یا VPS نیاز ندارد.

## امکانات فعلی
- رابط کاربری بومی اندروید و فارسی.
- بررسی صفحهٔ عمومی Suno و دریافت فایل فقط وقتی صفحه URL مستقیم صوتی عمومی را در متادیتای خود ارائه کند.
- اعتبارسنجی دامنه و HTTPS برای صفحه و فایل صوتی؛ عدم تلاش برای دور زدن ورود، پرداخت، محتوای خصوصی یا DRM.
- انتخاب فایل صوتی از حافظه و رمزگشایی/تبدیل آن به WAV (PCM 16-bit) روی دستگاه با MediaExtractor و MediaCodec.
- ذخیرهٔ خروجی در پوشهٔ `Music/Suno Studio`.
- تبدیل فایل محلی کاملاً آفلاین است.

## محدودیت‌های نسخهٔ فعلی
- لینک‌هایی که فقط صفحهٔ پخش باشند و URL مستقیم صوتی عمومی را ارائه نکنند، قابل دریافت نیستند؛ در این حالت باید از دانلود رسمی Suno استفاده شود.
- تبدیل محلی در این نسخه خروجی WAV دارد. فایل اصلی Suno با فرمت اصلی خود دانلود می‌شود. خروجی MP3 برای تبدیل فایل‌های محلی در مرحلهٔ بعدی اضافه خواهد شد.
- پشتیبانی از ورودی‌ها به رمزگشاهای صوتی دستگاه وابسته است.
- حداقل نسخهٔ اندروید 10 (API 29) است.

## ساخت APK
در GitHub به مسیر Actions برو و workflow با نام **Build Suno Studio Android APK** را اجرا کن. پس از موفقیت، artifact با نام `Suno-Studio-native-debug-apk` قابل دریافت است.

ساخت محلی با JDK 17 و Gradle 8.9:
```bash
cd android-native
gradle assembleDebug
```

## فناوری‌ها
- Kotlin و Android SDK
- Android MediaExtractor / MediaCodec برای پردازش صوت محلی
- Jsoup برای خواندن متادیتای صفحهٔ عمومی Suno
- بدون بک‌اند یا سرور واسطه

پروژهٔ وب قدیمی در ریشهٔ مخزن به‌عنوان نسخهٔ اولیه نگهداری شده است؛ APK جدید از پروژهٔ بومی `android-native/` ساخته می‌شود.
