# Suno Studio — Android مستقل

این مخزن اکنون روی اپلیکیشن بومی اندروید متمرکز است. برنامه برای پردازش فایل‌های شخصی به VPS، هاست، Node.js، Express یا سرور FFmpeg نیاز ندارد.

## قابلیت‌ها
- رابط کاربری بومی اندروید و فارسی با لوگوی اصلی پروژه.
- انتخاب فایل صوتی از حافظه با انتخابگر امن اندروید.
- تبدیل آفلاین فایل‌های صوتی پشتیبانی‌شده توسط رمزگشای دستگاه به WAV (PCM 16-bit).
- ذخیره خروجی در `Music/Suno Studio`.
- بررسی لینک عمومی Suno و دریافت فایل فقط در صورتی که صفحه عمومی، نشانی مستقیم صوتی را در متادیتای خود ارائه کند.
- بررسی HTTPS و دامنهٔ مجاز؛ عدم حدس زدن مسیرهای CDN و عدم دور زدن ورود، پرداخت، محتوای خصوصی یا DRM.

## محدودیت‌های شفاف
- لینک صفحهٔ آهنگ لزوماً لینک مستقیم فایل نیست. اگر صفحه نشانی مستقیم عمومی صوتی ارائه نکند، برنامه پیام می‌دهد که از دانلود رسمی Suno استفاده شود.
- تبدیل محلی در نسخه فعلی خروجی WAV دارد؛ MP3 محلی هنوز پیاده‌سازی نشده است.
- دانلود Suno به اینترنت و دسترسی‌ای که خود Suno مجاز می‌کند نیاز دارد.
- پشتیبانی از فرمت‌های ورودی به رمزگشاهای صوتی دستگاه وابسته است.
- حداقل Android 10 (API 29).

## ساخت APK
1. مخزن را در GitHub باز کن.
2. وارد بخش **Actions** شو.
3. گردش‌کار **Build Suno Studio Android APK** را اجرا کن (یا پس از هر تغییر در `android-native/**` منتظر اجرای خودکار بمان).
4. پس از موفقیت، artifact با نام `Suno-Studio-debug-apk` را دریافت کن.

ساخت محلی با JDK 17 و Gradle 8.9:
```bash
cd android-native
gradle assembleDebug
```

## فناوری‌ها
- Kotlin و Android SDK
- Android MediaExtractor / MediaCodec برای تبدیل آفلاین
- Jsoup برای خواندن متادیتای صفحهٔ عمومی Suno
- GitHub Actions فقط برای کامپایل APK؛ برنامهٔ نصب‌شده به GitHub یا سرور پروژه وابسته نیست.
